# 玩家角色 3D 模型存放區

這個資料夾用於存放真實的 3D 角色模型。

## 📥 載入規則

* **目標檔案**：遊戲引擎啟動時，會自動嘗試載入本目錄下的 `player.glb`。
* **降級機制 (Fallback)**：如果找不到 `player.glb`，或是載入發生錯誤，引擎會自動顯示原本用幾何體拼裝的「低模維修裝甲」，確保遊戲絕對不會崩潰白屏。

## 📐 模型建議規格

為了確保放入遊戲後能直接擁有良好的操作手感，請在匯出模型 (如 Blender) 時參考以下設定：

1. **檔案格式**：強烈建議使用 `.glb` 格式（包含網格、材質、骨架與動畫的單一檔案）。
2. **模型高度**：約 1.8 至 2.0 個單位 (Units) 最佳。
3. **模型朝向**：
   * 角色應朝向 **Z 軸正向 (+Z)** 或 **Z 軸負向 (-Z)**，具體取決於匯出設定。
   * 如果放進去後發現角色在橫著走（螃蟹步）或倒退走，請前往 `src/PlayerAvatar.js` 的 `onLoad` 區塊，調整 `model.rotation.y`（例如加減 `Math.PI / 2`）。
4. **模型大小**：
   * 如果放進去後角色像哥吉拉一樣大或像螞蟻一樣小，請前往 `src/PlayerAvatar.js` 的 `onLoad` 區塊，調整 `model.scale.set(x, y, z)`。
5. **動畫 (Animations)**：
   * 未來如果模型包含動畫，建議將動畫片段分別命名為 `Idle` (待機)、`Run` (跑步)、`Walk` (走路) 等標準名稱，以利後續 AnimationMixer 切換。
